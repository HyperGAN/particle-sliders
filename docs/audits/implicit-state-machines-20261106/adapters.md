## Inventory

### A01. Destructive native LoRA attachment

- **Carriers:** host instance `forward`, `LoRAModule.org_module`, `org_forward`, registered adapter modules.
- **States:** planned/unattached → initialized → attached (host calls adapter) → logically off/on via multiplier. There is no normal detach state/API.
- **Events/guards:** `lora_target_plan()` walks allowed host classes, filters the training method and deduplicates by module identity and exported name ([native_lora.py:80-143](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/packages/particle-sliders-core/src/particle_sliders/native_lora.py#L80)). `LoRAModule.apply_to()` saves the original method, assigns the adapter method, then deletes `org_module` ([native_lora.py:217-220](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/packages/particle-sliders-core/src/particle_sliders/native_lora.py#L217)). `LoRANetwork.__init__` attaches every target ([native_lora.py:284-310](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/packages/particle-sliders-core/src/particle_sliders/native_lora.py#L284)). Calling `apply_to()` twice on the same object fails because the carrier was deleted. A fresh network has no host-already-wrapped guard and may chain another adapter onto an existing one.
- **Failure behavior:** initialization validates name collisions before attachment, but the attachment loop has no transaction/rollback. Failure partway through leaves prior host forwards changed. Retaining/deleting the network reference does not restore host forwards.
- **Duplicate implementation:** [textsliders/lora.py:195-248,250-327](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/packages/particle-sliders-core/src/particle_sliders/textsliders/lora.py#L195) does the same lifecycle and explicitly calls `torch.cuda.empty_cache()` at construction end. [textsliders/dora.py:136-140,165-215](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/packages/particle-sliders-core/src/particle_sliders/textsliders/dora.py#L136) has the same destructive patch pattern plus a detached original-weight reference.

### A04. Sequence-envelope application

- **Carriers:** network and layer `seq_gain`, `seq_gain_mode`; current input dimensions and sequence length.
- **States:** uniform (`None`), scalar, prefix-truncated/padded, stretched/interpolated, ignored for non-2D/3D input.
- **Events:** `set_seq_gain()` detaches/copies an input envelope to FP32 CPU and writes every layer ([native_lora.py:373-390](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/packages/particle-sliders-core/src/particle_sliders/native_lora.py#L373); legacy copy [textsliders/lora.py:371-388](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/packages/particle-sliders-core/src/particle_sliders/textsliders/lora.py#L371)). Forward maps 2D/3D input to a sequence axis, moves gain to input placement, then broadcasts/interpolates ([native_lora.py:222-250](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/packages/particle-sliders-core/src/particle_sliders/native_lora.py#L222)). Enter re-applies network envelope; exit clears layer envelope while leaving network envelope configured.
- **Guards/failures:** `mode` has no whitelist; every value other than `prefix` follows stretch behavior. Empty envelopes have no guard and can reach `g[-1]` or interpolation; finite values are not checked. The network's configured state and layers' effective state can differ outside a context.

### A05. Continuous PEFT baseline-scale cache

- **Carriers:** each layer's `scaling` dictionary and `_krea_base_scaling` cache, plus optional `lora_scale`/`multiplier`.
- **States:** unbound baseline → first-call baseline captured → repeatedly scaled from baseline → recaptured when a new scaling key appears.
- **Events/guards:** first call snapshots current dictionary values; later calls use baseline times requested scale, avoiding cumulative multiplication ([native_lora.py:411-440](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/packages/particle-sliders-core/src/particle_sliders/native_lora.py#L411)). A newly seen scaling key causes recapture of *all current entries* ([native_lora.py:428-433](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/packages/particle-sliders-core/src/particle_sliders/native_lora.py#L428)).
- **Failure implication:** adding an adapter after an already scaled call can capture previously scaled entries as their new baseline. No invalidation checks device/topology/activation or finite scale; no rollback or context restoration. Historical duplicate exists in [textsliders/slider_targets.py:2375-2407](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/packages/particle-sliders-core/src/particle_sliders/textsliders/slider_targets.py#L2375).

### A06. Named PEFT scale ownership scope

- **Carriers:** discovered layer inventory, native paths, identity/device/dtype/schema, active adapter names, captured selected factors, fixed unselected values, prior/replacement dictionary identity.
- **States:** unbound → bound/preflight-valid → overridden → restored; topology/activation drift or ownership conflict → refused/error.
- **Events/guards:** binding requires supported stock PEFT Linear on `nn.Linear`, unmerged/enabled adapters, all selected names active and complete, no DoRA/variant, finite dictionaries ([peft_scaling.py:41-95](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/packages/particle-sliders-core/src/particle_sliders/peft_scaling.py#L41)). Every use re-discovers topology and checks schema and fixed values (`:97-107`). Scale is a finite real non-bool (`:11-20,119-129`).
- **Exit/failures:** installs new dictionaries and restores exact previous dictionary objects in reverse order. Checks that neither old nor installed dictionaries were mutated; refuses to overwrite another owner's external replacement (`:130-156`). Nested scopes scale from binding baseline, then restore previous values. Concurrent usage is documented unsupported (`:159-178`). Device movement invalidates binding because schema includes parameter device/dtype/identity (`:23-29`); training values/mode/grad changes do not invalidate it.

### A17. Native inference session open/observe/close

## Priority observations

1. **Most important shared ownership concern:** older activation contexts zero on exit instead of restoring caller state. This conflicts with nested observation scopes and concurrent request use unless a higher layer serializes access. There are already better local examples: A6 named PEFT and A7 YuE2 snapshots.
2. **Most important attachment concern:** general/legacy attachment permanently mutates live hosts; LTX broad PEFT fallback can proceed after partial mutation. This needs explicit attach/ready/failed/detached ownership or transactional rollback if fixed later.
3. **Most important recovery concern:** H3/LTX loaders mutate matching tensors before reporting missing keys; PEFT loaders can accept incomplete input. A9 Music3 shows the complete-validate-before-attach plus rollback pattern.
4. **OFF has several implementations:** compute-at-zero and real bypass are observably different in cost and behavior with invalid adapter tensors. Preserve that distinction in any proposed explicit machine.
5. **Capture object lifetime is broader than hook lifetime:** A19 accumulators survive exit, so re-entry means continuation of the old recording unless object recreation is guaranteed.
6. **Existing no-EMA mismatch:** inference exports still contain an EMA selection path. Report as source behavior, never enable it or propose an EMA comparison.

## Non-state-machine exclusions

`teachers.py` is pure tensor geometry plus threshold/guard branching (`lm_hold_dir`, `lm_blend_guard`, `lm_faithful_guard_e`). It chooses targets from function inputs, but stores no evolving state; it should not be counted as an implicit lifecycle. Similarly `qwen_native.predict()` and `with_encoding()` are stateless sequence-layout transformations/guards ([qwen_native.py:6-25](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/packages/particle-sliders-core/src/particle_sliders/qwen_native.py#L6)). Frozen capability descriptors and LTX recipe selectors are admission inputs; the changing factory/session/attachment that consumes them is the state machine.

All risks above are static source deductions. No runtime failures or successful model qualification are claimed.

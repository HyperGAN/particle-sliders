# Particle Sliders main: orchestration state-machine audit

Read-only source audit of `/ml2/particlesliders-working/implicit-state-machines-main-20261106`, origin/main `2b212c108637ca996d7676664547056066f2b22c`. No GPU jobs, models, services, network, publishing, or application mutations executed. Source line references below are relative to that root. `T/` abbreviates `packages/particle-sliders-core/src/particle_sliders/textsliders/`. This is an inventory of source behavior, including historical research workflows, not an endorsement of their scientific ranking policy. Several historical branches use CE/perceptual/collapse selection and EMA-labelled templates; standing user constraints supersede these on future execution.

The machines below are mostly *implicit*: string status values exist, but transitions emerge from file existence, counters, flags, subprocess results and guards spread across functions. A string `status` field alone does not constitute an explicit state-machine implementation.

## Pipeline and listening selection

**O01. Sweep stage/artifact lifecycle.** Carrier: models/<variant> `_last.json`, matching `.safetensors`, `pipeline_manifest.json`, per-seed render folders, `scores.json`, `REPORT.md`, `confirm-<winner>.json`. Inferred states: untrained → training → checkpoint-adoptable → rendered → scored → reported → held-out-confirmed; any stage can fail, and each CLI action can run separately. `train_stage` adopts an existing `_last.json` only if exactly one sidecar and matching weights exist and echoed recipe fields agree; otherwise it runs the trainer then validates and writes the pipeline manifest. Rendering requires valid weights/config; scoring requires measured ladders and nulls; report requires existing scores; confirm requires holdout seeds. No persisted global stage enum or transaction connects them. Refs: [scripts/slider_pipeline.py:117-184](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/scripts/slider_pipeline.py#L117); [slider_pipeline/stages.py:81-123](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/slider_pipeline/stages.py#L81), `128-151`, `160-192`, `388-443`, `448-451`, `593-637`. A partial `_last` artifact can block fresh training; adoption is limited to ECHO_KEYS and selected seeds rather than a full content identity.

**O02. Caption-pair onboarding admission.** Carrier: endpoint WAV presence per pole/seed and `onboard.json.certified/verdict`. States: endpoints missing → rendering → measured → CERTIFIED or REJECTED. Endpoint filenames decide rerender; pooled signed spans and permutation p determine certification; CLI exits 0 or 3. Refs: [slider_pipeline/stages.py:539-588](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/slider_pipeline/stages.py#L539); [scripts/slider_pipeline.py:158-170](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/scripts/slider_pipeline.py#L158). Endpoint adoption checks existence, not prompt/model/seed fingerprints, so reusing an output root with changed inputs can adopt stale evidence. The command comment says training is refused, but the independent `train` dispatch does not read `onboard.json` ([scripts/slider_pipeline.py:172-175](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/scripts/slider_pipeline.py#L172)).

**O03. DSP measurement cache.** Carrier: `.pipeline_features.json` containing WAV-name→mtime_ns fingerprint, expected duration, measured cells. States: missing/corrupt/stale → measured → cache hit; write failure leaves valid uncached result. Invalid JSON/OSError triggers recompute; exact fingerprint+duration enables reuse. Refs: [slider_pipeline/stages.py:197-225](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/slider_pipeline/stages.py#L197), `228-245`. Risk: feature-code/version and WAV content hashes are absent from identity; changed measurement implementation or preserved mtimes can retain stale measurements.

**O04. Gate/selection verdict lifecycle.** Carrier: per-variant `gates`, `pass`, scalar score, paired baseline evidence and retrain floor; final reports derive VETOED/baseline/TIE/other verdict. States are derived, not persisted transitions: missing null→unscoreable failure; any failed guard→VETOED; passed candidates can tie within retrain floor. Confirmation adds independent seed/long-window evidence. Refs: [slider_pipeline/gates.py:166-225](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/slider_pipeline/gates.py#L166); [slider_pipeline/stages.py:400-430](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/slider_pipeline/stages.py#L400), `456-465`, `593-637`. Ranking and eligibility are historical workflow behavior, separate from current RAW FP64 SSE directive.

**O05. Immutable benchmark/session preparation.** Carrier: `manifest.json`, `session-key.json`, public/session.json digest, copied content-named audio. States: absent → frozen benchmark → blinded session → answered. Existing manifest/session key rejects overwrite; candidate folders are skipped for absent scores/lyrics/seed/exact poles/audio; frozen manifest is digest-verified on load. Refs: [slider_selection/dataset.py:16-90](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/slider_selection/dataset.py#L16), `93-110`, `174-196`. No persisted explicit phase enum; artifact existence is the phase.

**O06. Response completion and automatic fit.** Carrier: append-only `responses.jsonl`, latest response per trial, `last_fit` in memory, calibration-status.json, model.json, score-preview.json. States: awaiting_listening → all trials answered → fitting → exploratory_fit_complete or needs_more_evidence. Submission requires same-origin (when supplied), bounded JSON body, valid trial/session/rating schema, and every relevant clip listed in `played`; append is fsynced under lock. All-trial coverage and changed digest trigger fit. Refs: [slider_selection/server.py:15-45](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/slider_selection/server.py#L15), `60-101`; [slider_selection/dataset.py:199-245](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/slider_selection/dataset.py#L199). `played` is declared client data, not proof of actual playback. Concrete retry risk: `last_fit[0]` is assigned before fit and retained after ValueError/FileNotFoundError; identical answers will not retry after external evidence/features are repaired, until another answer changes or server restarts ([slider_selection/server.py:31-44](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/slider_selection/server.py#L31)).

**O07. Listener label admission.** Carrier: latest response per trial, control outcomes, repeated-trial agreement, unsure handling. States: missing/unsure → unlabeled; any no→rejected label; all yes→usable label; controls+two repeats→listener_checks_pass. Preferences remain separate evidence. Refs: [slider_selection/dataset.py:199-245](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/slider_selection/dataset.py#L199). Latest answers replace earlier semantic labels while original JSONL history remains.

**O08. Exploratory model → independently validated selector.** Carrier: model.status, fit_id, validation report, candidate status/optimizer_score. Fit requires matching manifest, passed listener audit, ≥8 labeled ladders with ≥3 positives and negatives; output is exploratory. Validation returns rejected_overlap/no_labels/insufficient_or_failed/validated after disjointness and fixed accuracy/diversity/uncertainty checks. Scoring yields UNSCOREABLE when validation/coverage/provenance/range checks fail, FAIL for frozen-gate failures, otherwise SCORED. Refs: [slider_selection/model.py:72-103](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/slider_selection/model.py#L72), `122-168`, `171-214`. Explicit string verdict vocabulary, implicit cross-command lifecycle; validate returns a report, and does not itself mutate original model.status.

**O09. Learned-feature/model cache.** Carrier: file-content hash + provenance digest cache JSON, lazily loaded model fields. States: model unloaded→loaded; cache missing→measured→cached; cache with stale DSP fullband version→partial refresh. Provenance includes pinned model revisions, package versions, device type and protocol. Refs: [slider_selection/features.py:123-141](https://github.com/HyperGAN/particle-sliders/blob/2b212c108637ca996d7676664547056066f2b22c/slider_selection/features.py#L123), `143-193`. Stronger cache identity than pipeline mtime cache; malformed cache JSON raises rather than silently recomputing.

## Coverage and limits

Direct detailed reading: slider_pipeline stages and relevant gate/spec interfaces; slider_selection all lifecycle modules; queue_music3/yue2; train_yue2 wrapper and evaluation artifact commit; search_yue2 and Music3 sweep; distill/refine/verify/package/upload; representative legacy shell families and readiness shims; listen_server and watch_train state handling; reward_search queue/campaign, reward_preference campaign, reward_sliders campaign; reward_game controller/evaluate/worker/core/artifacts/confirmation/complete/intent/amendments and representative typed artifacts/variants. Repeated controller variants were compared line-for-line and differ only at three imports. Other typed confirmation/worker/prepare/archive families were source-scanned and grouped by observed corresponding phases; they were not each exhaustively read line-for-line. Static data, assets, retired Fibo and numerical training internals are outside this orchestration subaudit. Single-shot analysis/render scripts without resumption/selection/process lifecycle were not individually elevated to machines. This inventory does not constitute exhaustive semantic proof over every executable.

Strongest practical risk findings: finalist GPU lock self-deadlock; SQLite queue stranded running jobs; stale marker-only training wait; calibration retry digest set before successful fit; decided attempt marker committed before archive; partial final package blocks retry; existence-only distillation/render adoption; mtime-only DSP cache. None were modified or runtime-tested because this task is an inventory and forbids external/model/GPU execution.

# YuE2 GAN unipolar toy scoreboard (UniPG-B)

GAN-only ParticleGAN training on unipolar PairField toys (`divergent`, `close`).
Spine: Rp logistic + `GradRegularizer` champion (`b_cap`, `kappa=1`, `coeff=1`) on every arm.
No supervised MSE on G (no positive/cover/ending/FM/hold/plan/zero-point knob exists).
Teacher: raw positive caption. Scale 0 is the exact base by construction.
Generated by `analysis/slider2d/yue2_gan_exam.py` (propose_only). CPU only, no Hub, no GPU, no Music 3 weights.

## Gates (both required cells)

- cover @ scale +1 >= 0.85
- leak (off-caption) @ scale +1 <= 0.05
- neu_hold @ scale 0 >= 0.85

Eval scales 0 / 0.5 / 1 (gates read 0 and 1; 0.5 is a logged `half_cover` diagnostic).
Scale -1 is an unscored canary. Antipodal cos(+1,-1) is never consulted.

## Reading

- `baseline_learned12` FAILs at every budget (cover ~0.62-0.70): the learnable prior mean absorbs the pole shift, so the scored residual undershoots. Longer trains do not fix it (3400: 0.70).
- `unipg_b_frozen64` and `unipg_b_frozen32_init001` PASS both cells on all seeds at 1200 (and 3400) — earlier than 3400. The frozen zero-mean jitter bank forces the residual to carry the full shift; the wider/tighter bank stabilises divergent seed 1.
- `unipg_b_frozen32` needs 3400 to pass (divergent seed 1 overshoots at lower budgets). `unipg_b_frozen12` never stabilises seed 1.
- `unipg_b_center_vicregfaithful1` (learned + centered + faithful VICReg 1.0, var+cov-only, std_target 1.0) fixes divergent at 1200 (3/3 incl. seed 1) but undercovers close and degrades by 3400 — the closest ParticleRegularizer, still PARTIAL.
- `unipg_b_center_vicreg0` shows centering alone is not enough (divergent fails); `unipg_b_frozen32_2xlr` shows 2x LR + D 1.5x destabilises divergent seed 1 (leak 0.29).
- `neu_hold` is 1.000 everywhere by construction (scale 0 = exact base); `leak` is 0.000 on every pass.

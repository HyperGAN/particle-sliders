## New implementation and ownership

`pg09_remaining_worker.py` owns source/runtime/input checks, future native loads,
phase boundaries, frozen-base streams, pure common checkpoint/export utilities,
strict parity diagnostics and matched rendering. `ConditionalPG09` owns every
optimized objective, optimizer, constraint and training random stream. The worker
calls `run.step()` only; no optimized MSE or copied model-specific optimizer exists.
`particles=None` is explicitly an adapter GAN with released PG0.9 constraints,
not a claim of an attached particle bank. Both proposals select the actual public
`bispf_optimized` recipe and bind all resolved recipe fields, not a name-only label.

The existing common worker's pure packet/checksum/CPU-map, witness and guard
helpers are reused without edits. The shared packet schema's historic MOSS name
does not change the GAN objective. Full restore always deserializes on CPU so CPU
RNG bytes are never incorrectly moved to CUDA. Same-step immutable checkpoint
reuse requires full live packet equality. Export/reload checks and a separate
fresh-process state2-to-state3 replay compare raw losses, full state and sample
exactly, leaving checkpoint3 unchanged. No in-memory-only proof admits training.

Actual imported worker/helper/core/bootstrap/native paths and bytes, package
versions/origins/init-source hashes, resource guard, source/cache/old export
identities and native class/forward source files are checked. Supra's product
factory originally left its dynamic module unregistered. A new verified import
registration under the deterministic `supra_particle_model` namespace makes
native classes inspectable by the core. Different-origin/hash collisions fail
before import; failed imports restore the prior registry. Two fresh CPU processes
qualify identical synthetic classfile/forwardfile and actual core
`implementation_sources` signatures, without native forwards or weights.

The resource owner must still supply/review guardians, both inherited leases,
kernel/thermal monitoring and a source-bound safe MOSS-priority handoff receipt.
This worker never acquires leases or dispatches another process. A draft CLI
defaults to `plan` and live modes reject before model loading. Interrupted probe
or training writes a completed-step checkpoint and reports stopped; failed/stopped
outcomes require owner review and do not auto-retry. Resuming a stopped sustained
run is not automatically admitted by these phase cards.

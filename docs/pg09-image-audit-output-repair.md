# Image checkpoint audit output immutability repair

The original `ad47df3` script could overwrite an existing receipt or an input after reading it. This revision fixes that defect before any revised archive stage is admitted. Only isolated audit/proposal/test files change; core, active MOSS sources, model/checkpoint packets and the original proposal/evidence remain untouched.

`FreshReceiptOutput` requires an absent destination in an existing directory with no symlink components. It rejects lexical/resolved aliases of the plan, optional reviewed static receipt, script/source bindings, known packets and sidecars before any packet access. Existing files, hardlinks, ordinary/dangling symlinks and directory symlinks fail closed. The output directory is held by an open directory descriptor and its device/inode is rechecked; output freshness is also checked before each packet.

Publication writes a unique exclusive temporary file within that pinned directory, flushes and fsyncs complete JSON, then publishes through an atomic **exclusive hard link**. If any file or symlink appears at the final name between checks, publication fails without replacement. Temporary files are cleaned on serialization or publication failure. Repeating a command therefore needs a genuinely fresh output path; an existing receipt is never overwritten. The directory must already exist; the audit does not create output directories implicitly.

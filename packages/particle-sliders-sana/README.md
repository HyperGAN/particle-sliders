# particle-sliders-sana

Separate opt-in Sana neutral-caption velocity GAN backend for the shared
particle-sliders image lifecycle. Historical Sana UNI is unchanged.

See [the native contract and qualification limits](../../docs/sana-shared-gan.md).
No model loader, download, training on import, sampling pipeline or pretrained
qualification is included. Install this package in its own preview environment;
its exact core/PG/HyperGAN/HNDL source cohort is distinct from historical runs.
